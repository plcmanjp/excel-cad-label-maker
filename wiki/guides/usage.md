# 사용 설명

## 설치와 실행

[최신 릴리스](https://github.com/plcmanjp/excel-cad-label-maker/releases/latest)의 Windows ZIP을 새 폴더에 압축 해제하고 Excel_CAD_Label.exe를 실행하세요. EXE와 _internal 및 third_party 폴더를 함께 유지해야 합니다. Windows 64비트용 앱이며 Python 설치는 필요하지 않습니다.

## Excel 작성 규칙

- 첫 번째 시트의 각 열을 위에서 아래로 읽습니다.
- 한 셀의 글자가 라벨의 한 칸이 됩니다. 빈 셀을 넣으면 다음 라벨이 시작됩니다.
- 열 하나에 여러 라벨을 작성할 수 있으며 묶음의 줄 수에 따라 라벨 높이가 달라집니다.
- 수식을 사용하면 Excel에서 계산하고 저장한 뒤 파일을 선택하세요. 앱은 수식을 다시 계산하지 않습니다.

| 첫 번째 열 | 두 번째 열 |
|---|---|
| PUMP | MOTOR |
| START | RUN |
| 빈 셀 | 빈 셀 |
| PUMP | MOTOR |
| STOP | STOP |

위 예시는 두 열에 라벨 두 개씩을 만듭니다. 표의 빈 셀 위치에는 글자를 입력하지 마세요.

## 도면 만들기

1. .xlsx 또는 .xls 파일 한 개를 앱에 끌어다 놓거나 파일 찾기로 선택합니다.
2. 한 칸의 가로폭과 높이, 한 행의 라벨 수 및 라벨 간격을 지정합니다. 치수 단위는 mm입니다.
3. 글꼴과 테두리 및 문자 색상을 선택합니다. 긴 글자 자동 축소는 필요에 따라 켜거나 끌 수 있습니다.
4. DXF 도면 생성 및 저장을 누르고 저장 위치를 정합니다.
5. CAD에서 도면을 열어 글꼴, 정렬과 치수를 확인한 뒤 사용합니다.

여러 파일이나 Excel 임시 파일은 한 번에 선택할 수 없습니다. .xlsx 또는 .xls 원본 파일 한 개를 선택하세요.

## 출력 형식과 글꼴

DXF는 mm 단위이며 한글을 지원합니다. 테두리와 문자는 별도 레이어로 저장합니다. 사용하는 CAD에 선택한 글꼴이 없으면 표시가 달라질 수 있으므로 CAD에 설치된 글꼴을 선택하세요. 글꼴 파일은 앱에 포함하지 않습니다.

앱에서 DWG를 직접 저장하지는 않습니다. DWG가 필요하면 DXF를 CAD에서 열어 해당 CAD의 다른 이름으로 저장 기능을 사용하세요.

## 업데이트

앱을 실행하면 새 정식 버전을 확인합니다. 새 버전 알림의 릴리스 페이지 열기를 누르면 다운로드 페이지가 열립니다. 나중에를 누르면 현재 앱으로 작업을 계속할 수 있습니다. 하단 업데이트 확인으로 수동 조회할 수도 있습니다.

업데이트는 자동 설치되지 않습니다. 새 ZIP을 받아 별도 폴더에 압축을 풀고 새 앱을 실행하세요. 인터넷 연결이 없어도 라벨 작업은 계속할 수 있습니다.

## 파일 확인과 문제 보고

다운로드 ZIP의 SHA-256은 릴리스에 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.

[문제 보고](https://github.com/plcmanjp/excel-cad-label-maker/issues)에 앱 버전과 재현 방법을 알려주세요. 공개 게시물에는 고객 정보가 담긴 Excel 파일이나 도면을 올리지 말고 민감한 내용을 제거한 예제를 사용하세요.
