# 사용 설명

## 설치와 화면

[최신 릴리스](https://github.com/plcmanjp/excel-cad-label-maker/releases/latest)의 Windows ZIP을 새 폴더에 압축 해제하고 Excel_CAD_Label.exe를 실행하세요. EXE와 _internal 및 third_party 폴더를 함께 유지해야 합니다. Windows 64비트용이며 Python 설치는 필요하지 않습니다.

이 안내는 행 입력과 표 편집을 제공하는 0.4.0 빌드 기준입니다. 현재 공개된 0.3.0은 기존 열 입력과 텍스트 편집을 사용합니다. 새 버전은 업데이트 확인 버튼 또는 다운로드 페이지에서 받을 수 있습니다.

## 빠르게 도면 만들기

1. .xlsx 또는 .xls 한 개를 놓거나 파일 찾기(Ctrl+O)로 선택합니다. Excel 없이 시작하려면 출력 테이블 아래의 행 추가를 누릅니다.
2. 한 칸 가로폭과 높이(mm), 한 행의 라벨 수(개)를 확인합니다. 출력 데이터에서 문자와 원본 셀을, 도면 미리보기에서 배치를 확인합니다.
3. 경고가 있으면 출력 문자와 안내를 살펴보고 경고 내용 확인을 누릅니다. DXF 저장(Ctrl+S)을 눌러 저장 위치를 선택합니다.

정상 파일에서는 시트나 고급 설정을 따로 선택할 필요가 없습니다. 첫 시트, 전체 범위, 행 방식 및 기존 값 해석이 새 기본값입니다. 이전 버전의 설정이 있으면 기존 열 방식을 유지합니다. 고급 설정의 Excel 입력 방향에서 바꿀 수 있습니다. 저장 버튼 아래에는 준비 상태나 저장할 수 없는 이유가 표시됩니다. 저장 차단 오류는 원본에서 수정하고 저장한 뒤 다시 읽기를 누르세요.

기본 규격의 글꼴은 AutoCAD 표준 (Standard), 테두리와 문자 색상은 기본(검정)입니다. 저장된 마지막 설정과 사용자 프리셋은 그대로 재사용합니다. 검정 색상의 DXF 색상 번호는 7이며 CAD 배경에 따라 흰색으로 표시될 수도 있습니다. Standard 글꼴의 한글 표시는 사용하는 CAD에서 확인하세요.

저장 후 DXF 열기, 저장 폴더 열기 또는 다음 파일 선택을 사용할 수 있습니다. CAD 연결 프로그램이 없어 열기에 실패해도 저장된 DXF는 유지됩니다. 작업 취소는 안전한 중단 지점에서 반영되며 최종 저장이 끝난 경우에는 저장 완료로 안내합니다.

## Excel 작성과 입력 예제

한 행이 라벨 하나입니다. A열, B열, C열이 위에서부터 1줄, 2줄, 3줄이 됩니다. 마지막 값 오른쪽의 빈 셀만 제외하며 앞쪽과 중간 빈 셀은 빈 줄로 유지합니다. 완전히 빈 행은 라벨을 만들지 않습니다. 공백 문자는 입력한 그대로 유지합니다.

| A열 (1줄) | B열 (2줄) | C열 (3줄) |
|---|---|---|
| AAA | BBB | CCC |
| DDD | EEE | 빈 셀 |
| FFF | 빈 셀 | GGG |
| 빈 셀 | 빈 셀 | 빈 셀 |

위 예시는 3줄, 2줄, 가운데가 빈 3줄 라벨을 만듭니다. 빈 셀 위치에는 글자를 입력하지 마세요. 예제 버튼은 20개 라벨, 총 60칸의 합성 파일을 현재 입력 방향으로 저장하고 선택합니다. 현재 선택한 Excel 원본은 예제로 덮어쓰지 않습니다.

기존 파일은 고급 설정에서 기존 열 방식을 선택하세요. 각 열을 위에서 아래로 읽고 빈 셀에서 라벨을 나눕니다. 입력 방향은 숫자 표시 형식 해석과 별개이며 마지막 설정과 프리셋에 함께 저장됩니다.

여러 파일과 Excel 임시 파일은 선택할 수 없습니다. 잘못된 새 파일을 선택하면 기존에 확인한 입력을 유지하고 실패 이유를 알려줍니다. 손상, 파일 없음과 빈 결과는 안내에 따라 원본 및 시트와 범위를 확인하세요.

## 시트, 범위와 출력 문자

입력 범위에서 시트를 선택하거나 A1:C20 같은 범위를 지정합니다. 선택 범위의 첫 행 제외는 그 범위의 첫 행을 제외합니다. 제목 행, 숨김 행과 열은 자동으로 제외하지 않습니다. 병합 영역은 기준 셀만 읽고 나머지는 빈 셀로 처리합니다. 필터가 있는 시트도 숨김 데이터를 포함합니다.

출력 데이터에는 라벨 번호, 칸 수, 출력 문자, 원본 셀과 확인 건수가 표시됩니다. 목록이나 도면에서 라벨을 선택하면 같은 원본 정보와 크기, 실제 글자 높이 및 가로 배율을 확인합니다. 긴 목록은 100개씩 표시합니다. 도면은 보이는 영역에서 최대 200개 라벨을 표시하며 전체 배치 크기는 모든 라벨을 포함합니다. 확대하거나 선택 라벨로 자세히 확인하세요.

긴 라벨의 목록 요약은 첫 8칸을 보여줍니다. 더블클릭이나 편집 버튼으로 전체 문자를 확인하고 수정합니다. 진단은 전체, 저장 차단, 경고와 선택 라벨로 필터하고 200건씩 넘길 수 있습니다. 작은 칸은 라벨 윤곽으로 표시합니다.

시트의 읽기 범위는 최대 250,000셀입니다. 행 수와 열 수의 곱을 기준으로 하므로 멀리 떨어진 셀까지 데이터가 있으면 범위가 커집니다. 한계를 넘는 시트는 원본을 보존한 별도 파일로 나누어 사용하세요.

## 출력 데이터 직접 입력과 편집

테이블의 한 행이 라벨 하나입니다. 행 추가와 더블클릭 또는 편집 버튼은 같은 셀 표를 사용합니다. 출력 목록에서 Ctrl 또는 Shift로 여러 행을 선택한 뒤 편집을 누르면 선택한 라벨을 함께 수정합니다. Ctrl+A는 현재 페이지 전체 선택, Shift+위/아래/Home/End는 범위 선택입니다. Home/End는 현재 페이지의 첫/끝 행 선택, Enter는 편집입니다. 추가 창에는 여러 행을 붙여넣을 수 있으며 편집 창에서는 선택한 대상 행 수를 넘는 붙여넣기를 거부합니다.

편집 표에서 드래그 또는 Shift+방향키로 범위를 선택합니다. F2나 더블클릭으로 셀을 편집합니다. 한글도 셀 편집에서 입력하세요. 방향키는 셀 이동, Tab/Shift+Tab은 오른쪽/왼쪽, Enter/Shift+Enter는 아래/위 이동입니다. Ctrl+C/V/X로 범위를 복사, 붙여넣기, 잘라내기하고 Delete는 내용을 비웁니다. 추가 창의 행 삭제는 행 자체를 없앱니다. Ctrl+Z/Y는 한 동작씩 되돌리기/다시 실행이며 최근 기록만 보관합니다. 셀 편집 중 Esc는 입력 취소, 표에서 Esc는 창 취소, Ctrl+Enter는 적용입니다.

Excel에서 셀 범위를 복사해 표에 붙여넣고 수정한 범위를 다시 복사할 수 있습니다. 앞자리 0, 긴 숫자, 날짜나 수식처럼 보이는 문구를 앱에서는 문자열 그대로 사용하며 계산하지 않습니다. Excel로 돌려보낼 때는 붙여넣을 범위를 먼저 텍스트 형식으로 지정하세요. 일반 형식에서는 Excel이 숫자, 날짜와 수식으로 자동 변환할 수 있습니다. 셀 내부 줄바꿈과 탭은 셀 위치를 알려주고 거부합니다. 한 줄씩 옆 열로 옮겨 주세요.

편집 창은 가로/세로 스크롤과 선택 행의 줄 미리보기를 제공합니다. 긴 셀은 F2로 전체 문자를 확인하세요. 한 편집 표는 2,000,000자 및 행 수와 열 수를 곱한 250,000셀, 전체 출력은 250,000칸까지입니다. 편집 행을 모두 비우면 적용하지 않으며 취소로 원래 값을 유지할 수 있습니다. 편집한 행은 원본 셀에 수정 표시가, 새 행은 직접 입력으로 표시됩니다. 규격을 바꾸면 편집한 내용으로 도면을 다시 계산합니다.

수정과 추가는 앱의 작업 데이터에만 적용하고 원본 Excel에 기록하지 않습니다. Excel이 없어도 빈 테이블에 라벨을 추가하고 DXF로 저장할 수 있습니다. Excel의 해결되지 않은 입력 오류는 편집만으로 숨기지 않으며 원본을 수정하거나 새 작업에서 직접 입력하세요.

편집한 데이터가 있으면 다시 읽기, 새 Excel 선택, 새 작업과 입력 해석/범위 변경 전에 소실을 확인합니다. 취소하면 유지합니다. DXF를 저장한 뒤에도 다시 읽기는 Excel의 값을 불러오므로 확인합니다. 작업 데이터는 앱을 닫으면 보관하지 않으며 저장하지 않은 수정은 종료 전에 확인합니다. 필요한 결과는 DXF로 저장하세요.

## 기존 해석과 표시 형식

기존 해석은 표시 형식 대신 셀 값을 사용합니다. 정수 값은 1처럼 출력하고 문자열 001은 유지합니다. 행 방식은 다른 라벨의 숫자와 논리값에 영향을 받지 않고 공백을 보존합니다. 기존 열 방식은 같은 열의 숫자 0/1과 논리값에 먼저 나온 유형을 적용하고 양끝 공백을 정리하며 셀 줄바꿈을 한 줄로 연결하는 호환 동작을 유지합니다. 달라지는 출력 문자는 경고에서 확인합니다. 범위와 첫 행 제외는 실제 선택 데이터에 적용합니다.

고급 설정의 표시 형식 반영은 다음 형식을 지원합니다.

| 형식 | 예 |
|---|---|
| General과 문자 | 기존 값 또는 문자열 유지 |
| 0 패턴 1~15자리 | 숫자 1에 000을 적용하면 001 |
| 0.0 패턴의 소수 1~10자리 | 1.234에 0.00을 적용하면 1.23 |
| yyyy-mm-dd, yyyy/mm/dd | 2026-10-14, 2026/10/14 |
| yyyy-mm-dd hh:mm 또는 hh:mm:ss | 날짜와 24시간제 시간 |
| hh:mm, hh:mm:ss, h:mm, h:mm:ss | 24시간제 시간, h는 한 자리, hh는 두 자리 |

임의의 사용자 지정 표시 형식, 천 단위 구분과 퍼센트 등은 지원하지 않습니다. 미지원 형식은 기존 값 기반의 대체 문자를 보여주며 확인 후 진행합니다. 원본 문자나 도면 문구를 자동으로 자르거나 바꾸지 않습니다.

## 수식과 진단

앱은 수식을 재계산하지 않습니다. Excel에서 계산하고 저장한 뒤 선택하세요. 저장된 수식 결과가 최신인지도 보장하지 않습니다.

- .xlsx는 오류 셀, 수식 존재와 저장된 결과 누락을 검사합니다. 오류와 결과 없는 수식은 저장을 차단합니다. 저장된 결과를 사용하는 수식은 확인 경고를 표시합니다.
- .xls는 오류 셀, 값, 표시 형식과 병합 및 숨김 데이터를 검사합니다. 수식 출처와 결과 누락은 일반 값이나 빈 문자열과 구분할 수 없습니다. 한계를 확인하고 Excel에서 계산한 결과를 점검하세요. 필터 설정 자체도 진단하지 못하며 숨김 데이터는 포함합니다.
- 행 방식에서 셀 내부 줄바꿈, 탭과 제어 문자는 저장을 차단합니다. 기존 열 방식의 공백 문자열은 빈 출력으로 처리되어 라벨을 구분하고 진단에 표시합니다.

읽기 실패, 잘못된 규격, 빈 결과와 확정할 수 없는 입력은 저장할 수 없습니다. 경고 확인은 같은 결과에서 반복하지 않으며 입력이나 설정을 바꾸면 다시 확인합니다. 저장 전에 Excel 원본 변경을 발견하면 저장을 멈추고 다시 읽기를 안내합니다. 스타일을 바꿀 때는 확인한 입력을 재사용합니다.

## 글자와 도면 미리보기

가로폭과 높이, 간격 및 기본 글자 높이는 mm입니다. 기본 글자 높이에는 칸 높이에 대한 비율도 함께 표시합니다. 최소 글자 높이 경고는 출력 크기를 강제로 바꾸지 않고 너무 작아지는 라벨을 알려줍니다.

긴 글자는 자동 축소 및 압축할 수 있습니다. 실제 높이와 가로 배율을 확인하고 폭을 넓히거나 문구를 수정하거나 칸을 분리하세요. 자동 맞춤을 꺼도 넘침 가능성을 안내하며 원문을 자동 절단하지 않습니다.

전체 맞춤, 확대, 축소와 선택 라벨을 사용할 수 있습니다. 도면 영역에서 Ctrl과 마우스 휠로 확대/축소하고 화살표 키로 이동합니다. 미리보기와 저장은 같은 문자, 좌표, 크기와 글자 설정을 사용합니다. 글꼴 렌더링은 참고용이며 실제 CAD와 완전히 같지는 않습니다. 특수한 긴 문자는 가로 압축을 생략한 참고 표시 안내가 나타날 수 있습니다.

넓은 창에서는 설정과 결과를 나란히 보고 좁은 창에서는 설정 보기와 결과 보기로 전환합니다. 화면 배율에 맞춰 최소 창 크기를 조정합니다. 작은 편집 창에서는 안내와 미리보기를 줄여 셀 입력과 적용 버튼 공간을 확보합니다. 설정은 스크롤할 수 있습니다. Tab으로 주요 동작을 이동하고 Ctrl+Tab으로 데이터와 도면 탭을 전환합니다. 오류는 색상과 함께 문구로 표시됩니다.

## 설정 재사용과 복구

마지막 정상 규격은 앱을 닫거나 저장을 마칠 때 보관합니다. 새 파일을 선택하거나 앱을 다시 실행해도 재사용합니다. 기본 규격은 내장값이며 변경해 저장하지 않습니다.

이름 있는 프리셋은 저장, 불러오기, 이름 변경과 삭제를 지원합니다. 값을 바꾸면 수정됨이 표시되고 기존 이름으로 저장하거나 삭제할 때는 확인합니다. 프리셋에는 규격, 스타일, 입력 방향과 해석 모드만 들어가며 Excel 내용, 시트 이름, 입력 범위와 파일 경로는 저장하지 않습니다. 이전 설정과 프리셋은 열 방식으로 읽으며 새 기본 규격은 행 방식입니다.

손상된 설정과 알 수 없는 설정 버전은 보존하고 기본값으로 시작합니다. 설정 복구는 기존 파일을 백업한 뒤 기본값으로 복구합니다. 쓰기 권한과 디스크 문제로 설정 저장에 실패해도 변환 기능은 사용할 수 있습니다.

## 출력, 업데이트와 문제 보고

DXF는 AC1024, mm와 UTF-8을 사용하고 테두리와 문자는 별도 레이어에 저장합니다. CAD에 선택한 글꼴이 없으면 표시가 달라질 수 있습니다. 글꼴 파일은 포함하지 않습니다. DWG는 CAD에서 다른 이름으로 저장하세요. 앱에서 DWG를 직접 생성하지 않습니다.

상단 오른쪽의 업데이트 확인 버튼으로 새 정식 버전을 확인합니다. 새 버전이 있으면 버튼이 파란색의 새 버전 확인으로 바뀌고, 클릭하면 릴리스 안내를 볼 수 있습니다. 자동 확인은 팝업을 띄우지 않습니다. 업데이트는 자동 설치하지 않습니다. 새 ZIP을 별도 폴더에 풀어 사용하세요. 인터넷 연결이 없어도 로컬 라벨 작업은 계속할 수 있습니다.
