# 작업 저널 (CURRENT)

## 목표

- [Issue #1](https://github.com/plcmanjp/excel-cad-label-maker/issues/1)의 공개 개발 저장소와 0.1.0 원본 기준 릴리스를 구성한다.

## 현재 상태

- public 저장소와 900 기반 하네스 및 원본 소스를 구성했다. 원격 main과 릴리스 반영을 준비한다.
- 원개발자는 직장인, Fork 및 후속 개발자는 plcmanjp다. 원본 공개 재배포 허락을 확인했다.

## 주요 결정

- 0.1.0은 제공된 EXE의 변경 없는 기준 배포다. 원본 소스의 복구 구현과 빌드 재현은 후속 작업이다.
- 작업지시는 이 저장소의 GitHub Issues가 소유한다. 문서와 Git에 개인 경로 및 고객 자료를 넣지 않는다.

## 검증 결과

- 하네스 22개, 릴리스 거부 경계 6개, 등록 훅 4조건 및 공개 경계 검사가 통과했다. 독립 검수의 낮음 2건을 보정하고 delta 검수를 통과했다.
- UIA의 정확한 앱 창 실행과 실제 EXE 경로를 확인했다. 시각 캡처는 다른 창에 가려져 수용 검증 근거에서 제외했다. 원본 EXE와 ZIP 내부 EXE의 hash는 manifest와 일치한다.

## 미해결 사항

- 가져온 원본 Python 소스는 문법이 손상되어 빌드할 수 없다. EXE와 소스 대응 관계 및 외부 라이브러리 고지는 미확인이다.
- DWG 직접 출력과 전체 CAD 호환성은 미검증이다.
