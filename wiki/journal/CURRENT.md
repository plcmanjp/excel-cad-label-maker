## 주요 결정

- 소개 글의 다운로드와 업데이트는 공통 GitHub 릴리스 페이지로 연결한다. 본문과 이미지 원본은 Notion에서 관리하며 저장소에 복제하지 않는다. 앱 화면은 합성 문구를 사용한 예시로 설명한다.
- 시작 새 버전 팝업과 수동 재열기 및 모달 지연을 유지한다. 비교 버전은 별도 QC 진입점에서만 사용한다.
- 정식 tag의 source는 8498b03412e8a80c844967dca13803b145d11436으로 고정한다. 이후 기록 전용 commit은 공개 자산을 교체하지 않는다. 기존 공개 자산과 법적 고지 및 검증/복구 자료를 보존한다.
- 0.4.1 사용자는 수동 버튼이나 직접 다운로드로 한 번 갱신해야 한다. 시작 자동 팝업은 0.4.2부터 복원된다. 미지원 청소를 우회하지 않는다.
- 사용자 제공의 CAD 및 실사용 평가를 에이전트의 새 직접 검사나 정량 측정으로 확대하지 않는다. 배율 검증 제외를 PASS로 집계하지 않는다.
- 정상 원본 소스/EXE 대응 정보는 가능하면 확보하는 추가 자료다. 현재 복구 앱을 보관 원본 EXE의 같은 재빌드로 표현하지 않는다.

## 미해결 사항

- #27의 선행 공용 도구 지원 개선은 [부모 #52](https://github.com/plcmanjp/.agents/issues/52)와 [draft PR #54](https://github.com/plcmanjp/.agents/pull/54)가 소유한다. C: 캐시 회수와 복원 사전 검사는 완료했고 실제 사용자 대상의 Restore는 실행하지 않았다. D: 검증과 처리는 사용자 지시로 다음 세션에 재개한다. 회수한 checkout과 실제 receipt/계획 및 모든 복구 자료는 보존하고 진행 기록은 별도 clean checkout에 반영한다.
- 원래 checkout의 index/HEAD 및 작업 diff 지문은 사전/사후 같지만 원격 추적과 tag refs 변화가 관찰됐다. 이 세션은 그 폴더의 fetch/reset/prune/ref 쓰기를 실행하지 않았고 원인은 미확정이다. 전체 refs 무변경이나 동기화 완료로 판정하지 않는다.
