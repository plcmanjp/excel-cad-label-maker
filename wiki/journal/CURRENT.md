## 주요 결정

- README와 사용자 안내 및 릴리스 노트에는 제품 사용에 필요한 정보를 제공한다. 개발 안내는 기여자의 재현 가능한 절차로 작성한다. 사용자 문서 검사를 통해 내부 운영 문구와 기록 링크의 재유입을 차단한다.
- 원본과 외부 법적 고지 및 기존 공개 자산과 과거 journal 및 QC 기록은 보존한다. 기존 세 릴리스의 본문만 사용자 노트에 맞춰 정리했다.
- 업데이트 알림의 중앙 배치는 0.2.2에서 적용된다. 기존 실행 파일을 변경하거나 업데이트를 자동 설치하지 않는다.
- 기존 해석 모드를 기본으로 보존한다. 표시 형식 개선은 명시적 선택이며 .xls 수식 출처 진단의 한계를 알린다. 선택 범위와 제목 행 제외 뒤의 데이터를 혼합 타입 해석 기준으로 사용한다.
- 입력 내용과 경로는 프리셋에 저장하지 않는다. 신규 버전 부여, main 병합, tag 변경과 공개 릴리스는 현재 실행 범위에 포함되지 않는다.

## 검증 결과

- 제품 Python 3.13.15와 Tk 8.6.15, 하네스 Python 3.14.3을 사용한다. 제품81개 PASS, 배포16개 중15개 PASS 및1개 권한 SKIP, 하네스22개 PASS다. 저장소와 공개 문서 검사는 PASS다.
- source/frozen 실제 키보드 흐름과 두 환경의 Explorer 파일 드롭, frozen의 설정 복원과 대화상자 재진입 차단 및 덮어쓰기 거절과 취소를 확인했다. 생성 DXF5개의 문자와 배치 및 글자 속성 재읽기가 일치한다. 근거는 [Issue20 결과](../../project/qc/issue20-results.json)에 있다.
- 10,000개 라벨의 전체 변환 중앙값은 기존2.94초, 신규3.52초다. 추가 입력 진단 비용을 기록했다. UI 응답, 취소, 시작 시간과 폴더 크기는 [성능 비교](../../project/qc/issue20-performance.json)에 있다.

## 미해결 사항

- [Issue #14](https://github.com/plcmanjp/excel-cad-label-maker/issues/14)의 실제 CAD와 별도 PC 및 원본 대응과 이용 조건은 OPEN 및 미검증이다. DWG 직접 출력은 미지원이다.
- [Issue #20](https://github.com/plcmanjp/excel-cad-label-maker/issues/20)은 실제 초보 사용자 평가와 Windows 150%/200% 배율 검증을 남겨 OPEN으로 유지한다. DPI96에서 작은 창의 접근성을 확인한 근거를 실제 배율 PASS로 확대하지 않는다.
- 초기 GUI 자동화의 프리셋/색상 변경과 예제 대화상자 관측은 추적 재현과 최종 흐름에서 재현되지 않았다. 원인은 미확정이며 관련 관측을 QC에 보존했다.
