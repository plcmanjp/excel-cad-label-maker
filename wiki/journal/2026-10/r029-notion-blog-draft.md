## 요약

- Notion에 판넬 라벨 생성기의 블로그 소개 초안을 작성하고 사용자가 요청한 문체 수정까지 반영했다. 입력 예제, 파일 불러오기와 직접 입력, 프리셋, 글꼴과 앞자리 0, DXF 저장 및 업데이트를 설명한다.
- 특정 버전과 출시 이력 표현을 없애고 다운로드와 업데이트 링크를 공통 GitHub 릴리스 페이지로 통일했다. 반복되는 안내 문장과 이미지 캡션을 자연스러운 블로그 문체로 다듬었다.
- 정식 앱에서 합성 문구를 입력해 출력 데이터 목록, 스프레드시트 입력 표, 도면 미리보기와 고급 설정을 촬영했다. 원본 PNG 4장을 Notion에 올리고 캡션과 권장 배치 위치를 적었다. 앱 내부 미리보기와 CAD에서 연 도면은 구분했다.
- 초안과 이미지의 원본은 Notion에 둔다. 이 저장소에는 블로그 본문, 개인 경로, 업로드 인증 정보와 PNG를 복제하지 않았다. 블로그 공개 발행, 제품 변경, 빌드와 추가 청소는 수행하지 않았다.

## 검증

- 문단을 수정할 때 기존 문자열이 각각 한 번만 나타나는지 검사했다. 수정 후 Notion readback은 계획한 변경과 정확히 일치했고 기존 GitHub 링크와 이미지 4개의 참조가 유지됐다.
- 본문과 캡션에 특정 버전 번호가 없고 다운로드와 업데이트 링크 3개가 모두 공통 릴리스 페이지로 연결됨을 확인했다. 입력 예제 표와 줄바꿈 예제, 원개발자 직장인과 후속 개발자 plcmanjp의 크레딧, MIT와 이용 조건 안내를 유지했다.
- Notion에서 다운로드한 PNG 4개가 로컬 원본과 바이트 및 SHA-256이 일치했다. 원본 크기는 목록, 미리보기와 설정이 1123 × 792 px이고 입력 표는 685 × 568 px이다.
- 촬영에 사용한 실행 파일은 정식 0.4.2 배포물이며 SHA-256은 `a25e37bd0417e8a963fa32f84a8fe2dbfc0cf637f9d22e5fcf9463b232f9df36`이다. 별도 촬영용 사본을 사용하고 정상 종료했다. 사용자 설정은 백업한 바이트로 복원한 뒤 촬영 전 해시와 대조했다.
- `python -B .agents/scripts/check_repository.py`, `python -B .agents/scripts/check_public_docs.py`, `git diff --check`가 통과했다. 제품 코드와 공개 배포물은 바꾸지 않았다.
