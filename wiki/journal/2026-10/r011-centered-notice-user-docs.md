## 결정/판단 근거

- 사용자가 지정한 중앙은 바탕 화면이 아닌 실제 앱 창 기준이다. 실제 Tk 부모를 이동 및 크기 변경한 회귀 검사와 두 frozen 창의 중심 대조로 확인했다.
- 사용자에게 필요한 지원 범위와 이용 조건 및 크레딧은 유지했다. 과거 기록과 외부 고지 원문, 원본 및 아이콘과 기존 ZIP 및 tag는 보존했다. 기존 릴리스의 본문만 정리했다.
- 별도 알림 검수 entrypoint에서 낮은 입력 버전을 사용해 실제 GitHub API의 새 버전을 표시했다. 제품 소스 5개와 아이콘 hash가 정식 빌드와 일치하며 제품의 버전 override는 추가하지 않았다.

## 검증

- main CI: 제품40개, 릴리스16개, 하네스22개 총78개 PASS. 로컬은77개 PASS 및 native symlink 생성 권한으로1개 SKIP이며 원격 해당 시험은 PASS다.
- 독립 소스 검수 및 최종 ZIP과 receipt 및 manifest 대조 PASS. ZIP1129개 항목, 사용자 안내 TXT와 Markdown 출력0개, 외부 고지63개 원문 및 아이콘 보존 확인.
- frozen 알림의 두 앱 위치와 크기에서 수평 중심 오차0.5px, 수직0px. 실제 API 조회와 나중에 버튼 후 앱 사용 가능 확인.
- 최종 ZIP의 EXE를 실행해 합성 Excel을 Explorer에서 드래그했다. 파일 수신 화면과 라벨4개 저장 완료를 확인했다. DXF 재읽기 및 감사 오류0개, 기존 결과와 글자 및 위치와 스타일 일치.
- 정식 v0.2.2의 원격 tag 및 latest와 본문, 두 자산 및 ZIP과 체크섬 재다운로드 byte 일치. 최신 앱의 실제 수동 조회는 새 버전 없음, 공개0.2.2로 표시됐다.
- 기존 세 릴리스의 자산 ID와 크기 및 digest가 그대로다. 정확한 hash와 공개 결과는 [릴리스 QC](../../../release/qc/release-v0.2.2.json)에 있다.
