## 검증

- 수정 전 geometry 검사는 100/150/200% 모두 실패했고 안내 오른쪽 간격은 각각 90/123/112픽셀이었다. 수정 후 넓은/좁은 창 전환 및 오른쪽 정렬과 기존 선택 셀/편집 버튼 가시성 검사 3개가 통과했다.
- 전체 제품 128개, 저장소/공개 문서 및 Windows 개발 빌드 PASS. 로컬 배포 보호 15개 PASS, symlink 권한 부족 1개 SKIP. 최종 원격 검사 결과는 PR checks와 Issue 댓글에서 확인한다.
- 실제 EXE에서 버전 0.4.0, 기본 창과 최대화/복원 후 안내 배경과 마지막 파일 버튼 정렬을 시각 확인했다. source의 640픽셀 창과 설정 보기 전환 후 오른쪽 간격은 모두 0픽셀이었다.
- [QC 기록](../../../../project/qc/issue22-ui-results.json)에 실행 범위, 소스/EXE 해시와 geometry 근거를 보존했다. 새 EXE SHA-256은 eeb9ad581043e004eb28443c5a6fa136c5d52bb6ddf4b4dea86bff1f12728a2b다. 패키지 1,125파일과 복사본 해시가 일치한다.
- 실제 OS 배율, Excel 전체 왕복과 CAD 검증을 새로 실행했다고 주장하지 않는다. 이전 기능 QC 자료와 독립적으로 기록했다.
