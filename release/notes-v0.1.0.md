# Excel CAD Label Maker 0.1.0

전기함 작업용 덕트 라벨을 엑셀에서 DXF 도면으로 배치하는 Windows 무설치 앱의 첫 기준 릴리스입니다.

- 원개발자: 직장인 (닉네임)
- Fork 및 후속 개발: plcmanjp
- Windows ZIP을 풀고 Excel_Cad_Label.exe를 실행합니다.
- 라벨 크기와 간격, 글꼴, 색상 및 긴 글자의 자동 맞춤을 설정합니다.
- DXF를 출력합니다. DWG 직접 출력은 제공하지 않으며 필요하면 CAD에서 변환합니다.

이 배포는 제공받은 원본 EXE를 변경 없이 포함합니다. 0.1.0은 본 저장소의 배포 버전입니다. 현재 Python 원본에 문법 손상이 있어 본 저장소에서 재빌드한 결과가 아니며, 소스와 EXE의 빌드 대응 관계도 확인되지 않았습니다.

전체 CAD 호환성 및 출력 도면 수용 검증은 후속 작업입니다. 원본 재배포 허락을 확인했으며 세부 이용 조건은 NOTICE.md를 참고하세요. SHA256SUMS.txt로 ZIP 무결성을 확인할 수 있습니다.
