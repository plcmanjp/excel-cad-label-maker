# Excel CAD Label Maker 0.2.2

## 변경 사항

- 새 버전 알림이 실행된 앱 중앙에 표시되도록 수정했습니다.
- 사용 설명과 배포 안내를 더 간결하게 정리했습니다.

## 사용 방법

ZIP 전체를 새 폴더에 압축 해제하고 Excel_CAD_Label.exe를 실행하세요. 함께 들어 있는 _internal 및 third_party와 다른 파일을 유지해야 합니다. 업데이트는 자동 설치되지 않습니다.

Excel 파일 한 개를 앱에 끌어다 놓고 라벨 규격을 정한 뒤 DXF를 저장하세요. 사용법은 [사용 설명](https://github.com/plcmanjp/excel-cad-label-maker/blob/main/wiki/guides/usage.md)에 있습니다. DWG는 사용하는 CAD에서 변환해야 합니다.

원개발자는 직장인, 개발 및 관리자는 plcmanjp입니다. 이용 조건은 NOTICE.txt, 포함 라이브러리의 라이선스는 third_party 폴더를 확인하세요.
