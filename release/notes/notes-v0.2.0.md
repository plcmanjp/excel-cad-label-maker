# Excel CAD Label Maker 0.2.0

## 변경 사항

- .xlsx 또는 .xls 파일 한 개를 앱에 끌어다 놓아 선택할 수 있습니다.
- 입력과 규격을 확인하고 한글을 포함한 DXF 도면을 저장합니다.
- 새 정식 버전이 나오면 업데이트 알림에서 다운로드 페이지를 열 수 있습니다.
- 흰 라벨지에 ABC가 적힌 앱 아이콘을 적용했습니다.

## 사용 방법

ZIP 전체를 새 폴더에 압축 해제하고 Excel_CAD_Label.exe를 실행하세요. 함께 들어 있는 _internal과 다른 폴더 및 파일을 유지해야 합니다. 업데이트는 자동 설치되지 않습니다.

DXF를 CAD에서 열어 글꼴과 치수를 확인해 주세요. 앱에서 DWG를 직접 생성하지는 않습니다.

원개발자는 직장인, 개발 및 관리자는 plcmanjp입니다. 이용 조건과 포함 라이브러리의 라이선스는 배포물의 고지 파일을 확인하세요.
