# Excel CAD Label Maker 0.2.0

Excel 드래그 앤 드롭, GitHub 업데이트 알림과 ABC 흰 라벨 아이콘을 포함하는 후속 Windows 앱입니다. 별도 복구 소스로 빌드한 버전이며 변경 없이 제공된 기존 0.1.0 EXE의 재빌드가 아닙니다. 기존 v0.1.0은 보존합니다.

## 달라진 기능

- `.xlsx` 또는 `.xls` 한 개를 탐색기에서 앱에 놓으면 파일 찾기 없이 선택합니다.
- 라벨 규격과 입력을 검사하고 한글을 포함한 UTF-8 DXF를 저장합니다.
- 앱 시작 시 새 정식 GitHub Release를 확인하고 현재 및 최신 버전과 릴리스 페이지 열기 및 나중에를 안내합니다. 수동 확인도 제공합니다.
- EXE와 창에 흰 라벨지의 ABC 아이콘을 적용했습니다.

## 다운로드와 실행

`Excel-CAD-Label-Maker-0.2.0-windows-x64.zip` 전체를 압축 해제한 뒤 `Excel_CAD_Label.exe`를 실행하세요. `_internal`과 다른 폴더를 함께 유지해야 합니다. Python 런타임과 외부 라이브러리 고지가 포함됩니다. ZIP의 SHA-256은 SHA256SUMS.txt로 확인할 수 있습니다.

업데이트는 자동 설치하지 않습니다. 알림의 릴리스 페이지에서 새 ZIP을 받아 별도 폴더에 풀어 사용하세요. 기존 0.1.0 EXE에는 업데이트 알림이 없으므로 0.2.0을 먼저 설치한 사용자부터 이후 새 버전 안내를 받을 수 있습니다.

## 확인 범위

제품 및 빌드 검사, 공개 경계, Windows CI와 독립 검수를 확인했습니다. 합성 Excel 파일의 실제 드롭과 DXF 저장 및 읽기, 실제 GitHub API 기반 업데이트 알림과 릴리스 페이지 열기, 탐색기 및 창 아이콘을 검증했습니다. 최종 배포 ZIP의 EXE 실행과 파일 hash는 릴리스 검증 기록에서 확인합니다.

실제 CAD에서 글꼴과 도면 수용 및 Python 없는 별도 PC 실행은 아직 별도 확인 항목입니다. DWG 직접 출력은 지원하지 않습니다.
