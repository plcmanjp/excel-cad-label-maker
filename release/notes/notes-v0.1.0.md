# Excel CAD Label Maker 0.1.0

Excel 문자를 덕트 라벨용 DXF 도면으로 만드는 Windows 앱의 첫 공개 버전입니다. 제공된 원본 실행 파일이 변경 없이 포함됩니다.

ZIP 전체를 압축 해제하고 Excel_Cad_Label.exe를 실행하세요. DXF를 저장한 뒤 사용하는 CAD에서 글꼴과 치수를 확인해 주세요. DWG는 CAD에서 변환해야 합니다.

드래그 앤 드롭과 업데이트 알림을 사용하려면 [최신 버전](https://github.com/plcmanjp/excel-cad-label-maker/releases/latest)을 내려받으세요.

원개발자는 직장인, 개발 및 관리자는 plcmanjp입니다. 이용 조건은 배포물의 고지 파일을 확인하세요.
