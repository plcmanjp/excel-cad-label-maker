# Excel CAD Label Maker 0.4.2

앱을 시작할 때 새 정식 버전이 있으면 업데이트 안내 팝업을 표시합니다.

## 달라진 점

- 새 버전 확인 결과를 팝업으로 안내합니다. 파일 선택이나 편집 창이 열려 있으면 닫힌 뒤 표시합니다.
- 기존 수동 업데이트 버튼을 유지합니다. 안내를 닫은 뒤에도 상단 새 버전 확인 버튼으로 다시 열 수 있습니다.
- 최신 버전이거나 인터넷 조회에 실패한 경우 자동 팝업을 띄우지 않으며 라벨 작업은 계속할 수 있습니다.

Windows x64 ZIP 전체를 새 폴더에 풀고 Excel_CAD_Label.exe를 실행하세요. EXE와 _internal 및 third_party 폴더를 함께 유지해야 합니다. Python을 따로 설치할 필요가 없습니다. 업데이트는 자동 설치하지 않습니다.

행 기준 Excel 입력과 스프레드시트 편집, Arial 기본 글꼴 및 MIT 라이선스는 유지합니다. 입력은 .xlsx와 .xls, 출력은 DXF이며 DWG는 CAD에서 변환해 주세요.

원개발자는 직장인, 개발 및 관리자는 plcmanjp입니다. [MIT 라이선스](https://github.com/plcmanjp/excel-cad-label-maker/blob/v0.4.2/LICENSE)와 [이용 조건](https://github.com/plcmanjp/excel-cad-label-maker/blob/v0.4.2/release/package/NOTICE.md)을 확인하세요. 보관 원본 EXE와 외부 구성요소에는 개별 조건이 적용됩니다.
