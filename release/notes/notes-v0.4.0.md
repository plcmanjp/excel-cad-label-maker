# Excel CAD Label Maker 0.4.0

Excel의 한 행을 라벨 하나로 읽고, 앱에서도 셀 표로 라벨을 추가하거나 편집할 수 있습니다.

## 달라진 점

- A/B/C열을 라벨의 1/2/3줄로 사용합니다. 앞쪽과 중간 빈 셀은 빈 줄로 유지하고 오른쪽 끝 빈 셀과 전체 빈 행은 제외합니다.
- 여러 라벨의 추가와 일괄 편집, 범위 복사와 붙여넣기, 실행 취소와 다시 실행을 제공합니다.
- 기존 파일용 열 입력 방식을 유지합니다. 이전 설정과 프리셋도 열 방식으로 읽으며 고급 설정에서 입력 방향을 바꿀 수 있습니다.
- 작은 창과 화면 배율에 맞춰 입력 표와 버튼을 배치하고, 상단 드래그드롭 안내 오른쪽의 빈 공간을 수정했습니다.

## Excel과 함께 사용하기

Excel에서 범위를 복사해 편집 표에 붙여넣고 수정한 범위를 다시 복사할 수 있습니다. Excel로 돌려보낼 범위는 먼저 텍스트 형식으로 지정해야 앞자리 0과 긴 식별번호 등을 그대로 유지할 수 있습니다. 앱은 수식을 계산하지 않으며 셀 내부 줄바꿈과 탭은 위치를 안내하고 거부합니다.

Windows x64 ZIP 전체를 새 폴더에 풀고 Excel_CAD_Label.exe를 실행하세요. EXE와 _internal 및 third_party 폴더를 함께 유지해야 합니다. Python을 따로 설치할 필요가 없습니다.

지원 입력은 .xlsx와 .xls, 출력은 DXF입니다. DWG가 필요하면 CAD에서 변환하세요. CAD 글꼴과 한글 표시는 사용하는 CAD에서 확인해 주세요.
