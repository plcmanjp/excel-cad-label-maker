# Excel CAD Label Maker 0.3.0

Excel을 선택하면 출력 문자와 원본 셀, 확인할 항목 및 도면을 저장 전에 볼 수 있습니다. 원본 Excel은 변경하지 않습니다.

## 새로운 기능

- 출력 테이블을 더블클릭해 라벨을 편집합니다. 행 추가도 같은 창을 사용하며 Excel 없이 직접 입력할 수 있습니다. 한 줄이 도면의 한 칸이고 Ctrl+Enter로 적용, Esc로 취소합니다.
- 시트, 셀 범위와 첫 행 제외를 선택합니다. 입력 오류, 수식 결과 누락과 표시 형식의 한계를 안내하며 긴 글자와 최소 글자 높이를 확인합니다.
- 기본 규격과 프리셋을 재사용하고 마지막 정상 설정을 복원합니다. 기본 글꼴은 AutoCAD 표준 (Standard), 테두리와 문자는 기본(검정)입니다. 기존 사용자 설정은 유지됩니다.
- 읽기와 갱신 및 저장 중에도 화면을 사용할 수 있고 작업을 취소할 수 있습니다. 파일 교체와 재불러오기 전에 편집 데이터의 소실을 확인합니다.
- 상단 업데이트 확인 버튼은 새 버전이 있으면 파란색으로 바뀝니다. 자동 팝업은 띄우지 않습니다. 앱 소개와 버전 및 개발자 정보는 ? 도움말에서 확인합니다.

## 사용과 업데이트

Windows x64 ZIP 전체를 새 폴더에 압축 해제하고 Excel_CAD_Label.exe를 실행하세요. 함께 들어 있는 _internal과 third_party 폴더를 유지합니다. 업데이트는 자동 설치하지 않습니다.

작업 중 편집한 데이터는 앱을 닫으면 보관하지 않으므로 필요한 결과를 DXF로 저장하세요. 기존 해석이 기본이며 표시 형식 반영은 고급 설정에서 선택합니다. xls의 수식 출처와 결과 누락은 구분할 수 없습니다.

DXF AC1024, mm와 UTF-8 출력을 지원합니다. 색상7은 CAD 배경에 따라 검정 또는 흰색으로 보일 수 있고 Standard 글꼴의 한글 표시는 CAD 환경에서 확인하세요. DWG 직접 출력은 지원하지 않습니다. 고배율 Windows 화면과 다른 PC의 표시 상태는 환경에 따라 확인이 필요합니다.
