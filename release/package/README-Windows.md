# Excel CAD Label Maker

Excel의 글자를 전기함 덕트 라벨용 DXF 도면으로 만드는 Windows 64비트 앱입니다. Python을 별도로 설치할 필요가 없습니다.

## 사용 방법

1. ZIP 전체를 새 폴더에 압축 해제합니다. EXE와 _internal 및 third_party 폴더를 함께 유지하세요.
2. Excel_CAD_Label.exe를 실행합니다.
3. .xlsx 또는 .xls 파일 한 개를 앱에 끌어다 놓거나 파일 찾기로 선택합니다. Excel 없이 시작하려면 행 추가를 누릅니다.
4. 기본 규격을 확인하고 출력 데이터와 도면 미리보기를 확인합니다. 저장 차단 오류는 원본에서 수정하고 경고가 있으면 출력 문자를 확인하세요.
5. DXF 저장을 누르고 저장 위치를 선택합니다. 저장한 DXF를 CAD에서 열어 글꼴과 치수를 확인합니다.

새 기본값은 첫 시트의 한 행으로 라벨 하나를 만드는 행 방식입니다. A/B/C열은 라벨의 1/2/3줄이며 앞쪽과 중간 빈 셀은 빈 줄로 유지합니다. 오른쪽 끝 빈 셀만 제외하고 전체 빈 행은 건너뜁니다. 수식을 사용하면 Excel에서 계산하고 저장한 파일을 선택하세요.

시트와 셀 범위를 선택할 수 있고 마지막 정상 설정 및 이름 있는 프리셋을 재사용합니다. 이전 설정과 프리셋은 기존 열 방식을 유지합니다. 세로로 작성한 파일은 고급 설정의 Excel 입력 방향에서 기존 열 방식을 선택하세요. 입력 방향과 별도로 기존 해석이 기본이며 표시 형식 반영도 고급 설정에서 선택합니다. xls의 수식 출처와 결과 누락은 구분할 수 없습니다. 지원하지 않는 표시 형식은 대체 출력 문자를 확인해야 합니다. 원본 파일이 바뀌면 다시 읽기로 결과를 확인하세요.

행 추가와 테이블 더블클릭은 같은 스프레드시트 편집 창을 엽니다. 편집 표의 한 행이 라벨 하나이고 열마다 한 줄입니다. 여러 라벨을 추가하거나 출력 목록에서 여러 행을 선택해 함께 편집할 수 있습니다. F2 또는 더블클릭으로 셀을 편집하고 Ctrl+C/V로 범위를 복사하거나 붙여넣으며 Ctrl+Z/Y로 되돌리거나 다시 실행합니다. Ctrl+Enter로 적용하고 Esc로 취소합니다. 셀 편집 중 Esc는 셀 입력 취소이며 편집 대상 행 수를 넘는 붙여넣기는 거부합니다.

Excel로 돌려보낼 대상 범위는 먼저 텍스트 형식으로 지정하세요. 앱은 001, 긴 숫자와 수식 모양의 문구를 문자열로 유지하며 계산하지 않습니다. 셀 내부 줄바꿈과 탭은 위치를 안내하고 거부하므로 한 줄씩 옆 열에 입력하세요. 작업 데이터만 바꾸고 원본 Excel은 수정하지 않습니다. 작업 데이터는 앱을 닫으면 보관하지 않으므로 필요한 결과를 DXF로 저장하세요.

새 기본 규격은 Arial 글꼴과 검정 테두리/문자입니다. 저장된 사용자 설정과 프리셋의 글꼴은 그대로 재사용합니다. 기존 설정을 바꾸려면 고급 설정의 글꼴에서 Arial을 선택하세요. CAD 배경과 글꼴에 따라 색상과 한글 표시가 달라질 수 있습니다. 한글이 물음표로 보이면 굴림 등 한글 글꼴을 선택해 다시 저장하고 사용하는 CAD에서 확인하세요.

## 업데이트

상단 업데이트 확인 버튼은 새 버전이 있으면 파란색의 새 버전 확인으로 바뀝니다. 클릭해 릴리스 안내를 확인하고 새 ZIP을 받아 별도 폴더에 풀어 사용하세요. 자동 팝업과 자동 설치는 하지 않으며 인터넷 연결이 없어도 라벨 작업은 가능합니다.

## 지원 형식과 이용 조건

입력은 .xlsx와 .xls, 출력은 DXF입니다. DWG는 CAD에서 변환해 주세요. CAD의 설치 글꼴에 따라 문자 표시가 달라질 수 있습니다. 글꼴 파일은 포함하지 않습니다.

원개발자는 직장인, 개발 및 관리자는 plcmanjp입니다. 이용 조건은 NOTICE.txt, 크레딧은 CREDITS.txt, 포함 라이브러리의 라이선스는 third_party 폴더에서 확인하세요.

앱 소개와 버전 및 두 개발자의 정보는 상단 ? 도움말에서도 볼 수 있습니다.
