# 이용 조건

## 소스와 현재 앱

이 저장소의 소스코드와 0.4.1부터 제공하는 후속 앱에는 MIT 라이선스가 적용됩니다. 저작권자는 plcmanjp이며 원개발자 직장인의 크레딧을 유지합니다.

MIT는 상업적 이용, 수정과 재배포를 허용하며 복사본 또는 소프트웨어의 상당 부분에 저작권 및 라이선스 고지를 포함해야 합니다. 소프트웨어는 보증 없이 제공됩니다. 정확한 조건은 저장소의 LICENSE와 앱 폴더의 LICENSE.txt 원문을 확인하세요.

## 보관 원본 실행 파일

보관 버전 0.1.0에 포함된 원본 EXE는 제공된 파일 그대로이며 위 MIT 적용 선언의 대상이 아닙니다. 이 실행 파일의 공개 재배포는 별도로 받은 허락에 따릅니다. 소스에서 다시 빌드한 파일이 아니며 해당 보관 버전의 고지를 확인하세요.

## 외부 구성요소와 글꼴

최신 앱에 포함된 외부 라이브러리와 Python 및 Tk에는 각 구성요소의 라이선스가 적용됩니다. 원문은 third_party 폴더에서 확인하세요. 앱의 MIT 라이선스로 외부 구성요소의 조건을 대체하지 않습니다. 이 라이브러리 고지 목록은 보관 버전 0.1.0 실행 파일의 내부 구성 목록이 아닙니다.

글꼴 파일은 배포물에 포함하지 않습니다. 선택한 글꼴의 사용 조건은 해당 글꼴의 라이선스를 따릅니다.
