# 이용 조건

원본 프로그램과 Python 소스의 원개발자는 직장인입니다. 원본은 공개 재배포 허락을 받아 제공합니다.

원본에 별도의 오픈소스 라이선스가 지정되어 있지 않습니다. 이 저장소의 공개만으로 제3자의 수정, 상업적 이용이나 추가 재배포 권한이 부여되지는 않습니다. 해당 이용에는 원권리자의 라이선스 또는 별도 허락을 확인해야 합니다.

최신 앱에 포함된 외부 라이브러리와 Python 및 Tk의 라이선스는 third_party 폴더에서 확인하세요. 외부 라이브러리의 라이선스는 원본 프로그램의 라이선스를 대신하지 않습니다. 이 라이브러리 고지 목록은 보관 버전 0.1.0 실행 파일의 내부 구성 목록이 아닙니다.

글꼴 파일은 배포물에 포함하지 않습니다. 선택한 글꼴의 사용 조건은 해당 글꼴의 라이선스를 따릅니다.
